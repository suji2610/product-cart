# Online Shopping Cart System using Java

## Overview
The Online Shopping Cart System is a simple console-based Java application that allows users to browse products, manage their shopping cart, calculate discounts, generate bills, and save order details to a text file.

This project demonstrates the practical implementation of basic Java programming concepts through a real-world shopping application.

## Features
- **Display Products:** View available products with their ID, name, category, price, and stock quantity.
- **Search Products:** Search for products by name.
- **Add to Cart:** Add products to the cart while checking stock availability.
- **Remove from Cart:** Remove selected products and restore their stock.
- **Update Quantity:** Modify the quantity of products in the cart.
- **View Cart:** View selected products, quantities, and prices.
- **Calculate Total:** Automatically calculate the total purchase amount.
- **Apply Discounts:** Apply discounts based on the purchase amount.
- **Generate Bill:** Display the final bill with the total, discount, and payable amount.
- **Save Order:** Store order details in a text file using Java file handling.

## How to Run

### Prerequisites
- Java Development Kit (JDK) installed
- A Java-compatible IDE or terminal

### Steps
1. Clone this repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd <your-project-folder>
   ```
3. Compile the Java file:
   ```bash
   javac Main.java
   ```
4. Run the program:
   ```bash
   java Main
   ```

**Note:** Ensure that the Java filename matches the public class name. If your file contains `public class Main`, save it as `Main.java`.

## 🛒 How It Works
1. Launch the application.
2. Select an option from the displayed menu.
3. Browse or search for products.
4. Add products to the cart and manage quantities.
5. View the cart and calculate the total.
6. Apply applicable discounts and generate the final bill.
7. Save the order details to `order.txt`.
8. Exit the application.
